# README の同期

## 手順

1. 空のデータの置き場所を用意する（`PORTFOLIO_HUB_HOME` を空の一時ディレクトリに向ける）。
2. README のコマンドを、上から順に書いてあるとおりに実行する。
3. 実際の出力と README の出力例を比べ、違いがあれば README を直す。
4. 一時ディレクトリを消す。

## チェックポイント

- 手順を再現できるか：README だけを読んで、新しく clone した状態から最後まで進められる。
- 出力が一致するか：README の出力例と、実際の出力が同じである（行末の空白は除く）。
- 古い記述がないか：消したり名前を変えたりしたコマンド、オプション、環境変数が残っていない。
- 設定の表が正しいか：環境変数の名前と既定値が、`*Env` クラス（`env.py`、`log.py`、`sqlite/`、`rez/`）と一致する。
- バッジとリンクが切れていないか。
